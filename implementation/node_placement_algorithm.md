## 1. 幾何学的基盤 / Geometric Foundation

### 葉序（Phyllotaxis）モデル

5,400ノードを黄金角 **137.508°** に基づくフェルマー螺旋状に配置。

**極座標変換:**

```
r(n) = c√n          # c: ノード間距離制御定数
θ(n) = n × 137.508°

n: 1 ≤ n ≤ 5,400
```

> ⚠️ **物理制約（Grok確定）:** 最小ノード間距離 ≥ 3–5mm 必須
> 
> - d=1mmノード基準: spacing ≥ 3d = 3mm
> - 推奨c値: c ≥ 0.7mm（間距離3–4mm確保）
> - 根拠: spacing < 3D時にwake interferenceで振幅低下・出力相殺リスク
> - Phase 2（54ノード）で加算効率80%以上維持の必要条件

-----

### 修正版数式：Dynamic Coefficient Phyllotaxis（Gemini設計）

**角度（全ノード共通）:**

```
θ(n) = n × 137.5077° (mod 360°)
```

**半径（動的係数型）:**

```
r(n) = c(n) × √n
```

**動的距離係数 c(n):**

```
c(n) = c₀ × (1 + α × n/N_total)

c₀        = 0.7    # Grok推奨最小開始係数
α         = 0.15   # 外周に向かう拡散係数（エントロピー排出路確保）
N_total   = 5,400  # 総ノード数
```

**効果:**

- 中心部の密集を回避
- 全域でノード間距離 s ≥ 3–5mm を維持
- 外周ほど密度がわずかに低下 → 流体の逃げ道を確保

-----

### トポロジカル・ボイド配置スキップ範囲 / Void Skip Ranges

> **定義:** n は全ノードの通し番号（1 ≤ n ≤ 5,400）。
> 各ステージ k（初項18・公差18の等差数列）の通し番号範囲は
> **n = 9k(k−1)+1 〜 9k(k+1)** で与えられる。
> Stage 5: n = 181–270（90ノード）／ Stage 14: n = 1,639–1,890（252ノード）

```
Stage 5  (n = 181–270 内):    n = 220–230   をスキップ（11箇所、段中央）
Stage 14 (n = 1,639–1,890 内): n = 1,757–1,772 をスキップ（16箇所、段中央）
```

> **実装ノード数への影響:** スキップ位置はノードを置かない空隙（ボイド）であり、
> 実装ノード数は 5,400 − 27 = **5,373**。
> P_total は加算効率80%込みの見積りのため、
> 5,373 × 1.2nW × 0.80 ≈ 5.2μW となり、シミュレーション確定値 5.1μW と整合する。

**効果:**

- カルマン渦の「溜まり」を解消
- 低Re数域での流体停滞を防止
- Prigogine開放系を物理的に維持

**採用理由:**

- 自然界で最も効率的な空間充填（植物の種・葉配置で実証済み）
- 低Re数（Re ≈ 40–200）での渦衝突を均等分散
- 特定箇所への負荷集中（不協和音・乱流）を防止

## 3. 流体力学整合性 / Fluid Dynamics Validation

*Grok レビュー結果*

### ポジティブ評価 ✅

- 黄金角螺旋は低Re数で渦衝突を回避しやすい
- ボイド（Stage 5/14）が滞留防止に寄与
- VIV文献：tandem配列で渦干渉利用による出力34%向上の報告あり

### 懸念事項 ⚠️

- d=1mm微小ノード×5,400個の低Re流れでは「渦増幅」より「干渉による乱れ増大」リスク
- 黄金角螺旋は光学・ナノスケールで主に使用、流体VIVハーベスタではtandem/parallel配列（spacing 2–6D）が主流
- 低Re（<200）でKarman渦列が不安定化（3D化・遷移）する可能性

### 改善・対処 🔧

- **最小ノード間距離 ≥ 3–5d** を必須パラメータとして追加（c値で調整）
- CFD検証推奨：OpenFOAM等で黄金角配列 vs グリッド/ランダム配置の渦パターン・振幅比較
- ボイド活用はGood → 乱流抑制効果として維持
